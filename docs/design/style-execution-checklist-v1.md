# Style Execution Checklist v1

- Source: StyleKit `Corporate Clean` + World-Link 产品约束 + 本轮 Sidepanel 落地范围
- Status: active
- Last Updated: 2026-04-19

## 1. 目标

本清单用于把风格判断转成稳定可执行规则，避免“口头上选了 Corporate Clean，代码里仍混入展示型装饰”。

当前目标不是重做界面，而是把主工作区收敛到：

- 主风格：`Corporate Clean`
- 辅助风格：`Notion-style` 的文本排版节奏
- 动效策略：微交互优先，细小 hover / active / focus 反馈，不引入强表演性动效

## 2. 适用范围

### 2.1 当前必须遵守

- Chrome Sidepanel 主工作区
- 网页采集弹窗
- 后续 Web 工作台的产品界面

### 2.2 可以局部借用

- 文档说明区
- 空状态说明
- 帮助文案与术语解释

### 2.3 不在当前范围

- 营销站 / 官网落地页
- 高展示属性的品牌页

## 2.4 侧边栏优先约束

当前主形态是 `Chrome Sidepanel`，因此所有样式判断都必须先服从窄栏工作流，而不是普通后台大屏逻辑。

必须优先保证：

- `320–400px` 宽度下首屏不拥堵
- 重要操作一屏可达
- 不依赖双列和宽表格才能完成主要任务
- 文案、按钮、标签、徽标不会把横向空间挤爆
- Header、上下文卡、Tab、工作区保持稳定垂直节奏
- 动效只做短促微反馈，不打断高频操作

禁止：

- 把 Sidepanel 做成缩小版大后台
- 依赖大 Hero、宽横幅、复杂分栏
- 在窄栏里堆叠过多品牌装饰
- 为了展示感牺牲可扫描性

## 3. 主风格执行规则

参考 StyleKit `Corporate Clean` 的直接使用建议，主工作区应遵守：

- 页面背景使用 `bg-slate-50` 一类浅灰白底，不使用大面积强渐变
- 卡片使用 `bg-white + border-gray-200 + shadow-sm + rounded-xl`
- 主操作使用蓝色系，优先 `blue-600 / blue-700`
- 标题使用 `font-semibold tracking-tight`
- 可交互元素必须有 hover / active / focus 状态
- 按钮和输入框优先 `rounded-lg`
- 阴影只允许 `shadow-sm ~ shadow-md` 级别

禁止项：

- `shadow-2xl` 或重投影
- 主工作区大面积渐变背景
- 霓虹、玻璃拟态、强品牌炫光
- 过度鲜艳色彩组合
- 为了“高级感”牺牲可读性的低对比文本

## 4. 辅助风格借用规则

`Notion-style` 只用于提升可读性，不进入主框架视觉。

允许借用的点：

- 标题与正文之间更舒展的段落节奏
- 说明文本的留白与层级
- 空状态中的“解释 + 下一步 CTA”表达
- 术语说明 / 帮助块的低压迫感排版

禁止借用的点：

- 把列表区做成文档编辑器质感
- 让工具面板失去边界感
- 用过大的留白替代结构层次

## 5. 组件级执行清单

### 5.1 Brand Header

- 保持工具栏感，而不是品牌横幅
- 品牌区、刷新动作、账号区层次清晰
- 使用浅边框和白底，不做重色头图

### 5.2 Global Context Card

- 世界观库 / 当前作品是最关键上下文
- 选择器和 CTA 要优先清晰，不做复杂装饰
- 术语提示块使用“轻说明”风格，不抢主操作

### 5.3 Primary Tab Bar

- 更像“工作模式切换器”，不是营销导航
- active 态突出但不刺眼
- 图标只作为辅助识别，不做视觉主角

### 5.4 Section Card / Overview Card

- 卡片层级稳定、边界清楚
- 概览卡允许比普通卡片多一点强调，但不能引入展示型渐变
- 指标卡优先“先读懂，再比较”

### 5.5 Entity / Capture Card

- 内容信息优先于标签装饰
- 标签 / 状态 / 次数徽标必须可扫描
- hover 反馈要轻，不做大位移

### 5.6 Empty / Loading / Error State

- 全部要和主风格统一
- 允许细小动效，但必须服务于“状态可理解”
- 错误态优先给出恢复路径

## 6. 动效执行规则

本轮动效只采用“微交互”路线：

- hover：轻微提亮、轻微升起、阴影微升
- active：轻微按压感，不做 scale
- focus：明显可见但克制的 ring
- 进入动画：短时淡入上移

禁止：

- 大幅位移
- 长时间弹跳
- 强烈缩放
- 与业务无关的装饰动画

## 7. 本轮落地范围

本次代码优化至少覆盖：

1. 主题 token 收敛
2. 全局卡片、按钮、输入框层级统一
3. Brand Header 优化
4. Tab Bar 优化
5. 创作上下文区优化
6. 概览卡与灵感卡优化
7. Loading / Error / Inline Message 统一

## 8. 后续规则

1. 新增样式前先判断是否符合 `Corporate Clean` 主风格。
2. 若只为“更好看”而引入渐变、强投影、重装饰，默认拒绝。
3. 若新增页面需要更强品牌表达，必须先说明是否属于营销域。
4. 风格层调整优先改 token 与全局类，不优先在业务组件里写死。
