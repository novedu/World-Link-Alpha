## 1. 产品定位

### 1.1 核心定位
World-Link Alpha 是一个面向虚构世界观创作者的**设定采集与结构化管理工具**，通过 Chrome 插件的形式，提供网页划词采集和 Sidepanel 管理双入口，帮助创作者快速收集灵感、结构化管理设定资产，并实现跨作品复用。

### 1.2 目标用户

#### 核心用户
- **长篇网文作者**：需要管理大量设定，跨多本书复用
- **剧本杀作者/主笔**：需要构建复杂的世界观和角色关系
- **独立游戏叙事设计者**：需要管理游戏世界的设定和剧情

#### 次级用户
- **TRPG 主持人**：需要管理游戏设定和角色关系
- **世界观设定爱好者/OC 玩家**：喜欢构建和管理虚构世界

### 1.3 核心价值主张
1. **即时采集**：30秒内完成网页划词到设定创建
2. **跨作品复用**：世界级资产与书级使用视图共存
3. **结构化管理**：搜索、过滤、关系维护，提升管理效率
4. **AI 辅助**：智能总结、扩写、冲突检测，提升创作质量

## 2. 场景示例

### 2.1 场景一：网文作者的灵感采集
**用户**：长篇网文作者
**痛点**：浏览网页时看到好的设定灵感，无法及时记录和结构化管理
**解决方案**：
1. 在网页中选中文本（如地名、势力、物品描述）
2. 右键点击「存入 World-Link」
3. 填写世界、类型、名称、描述等信息
4. 保存后自动创建设定并关联到当前作品

**价值**：灵感不丢失，设定结构化管理，后续写作可直接复用

### 2.2 场景二：剧本杀作者的关系管理
**用户**：剧本杀主笔
**痛点**：需要管理复杂的角色关系和世界观设定，容易出现逻辑冲突
**解决方案**：
1. 在 Sidepanel 中创建世界观库和多个剧本项目
2. 为每个角色、地点、势力创建设定卡
3. 使用关系编辑器维护角色之间的关系
4. 使用 AI 冲突检测检查设定中的逻辑矛盾

**价值**：关系可视化，逻辑冲突提前发现，提升剧本质量

### 2.3 场景三：游戏设计者的世界构建
**用户**：独立游戏叙事设计者
**痛点**：游戏世界设定量大，需要跨多个游戏项目复用
**解决方案**：
1. 构建世界级设定库，包含种族、职业、地图、规则等
2. 为每个游戏项目创建独立的书项目
3. 从世界级设定中选择需要的设定绑定到具体游戏
4. 使用时间轴管理游戏世界的历史事件

**价值**：设定复用，世界一致性，开发效率提升

## 3. 用户社区建设

- 建立活跃的创作者社区，促进用户交流和知识分享
- 收集用户反馈，持续改进产品
- 培养用户忠诚度，提升产品口碑

### 3.2 社区平台
1. **Discord 服务器**：创建专属社区，包含以下频道：
   - 通用讨论：产品使用、功能建议
   - 创作分享：用户作品展示、设定分享
   - 技术支持：问题解答、使用教程
   - 反馈建议：产品改进、新功能需求

2. **GitHub Discussions**：用于产品相关的技术讨论和问题追踪

3. **社交媒体**：
   - Twitter/X：产品更新、使用技巧、用户故事
   - 小红书：创作案例、使用教程
   - B 站：视频教程、功能演示

### 3.3 社区活动
1. **设定大赛**：定期举办设定创作大赛，鼓励用户分享优质设定
2. **创作者访谈**：邀请知名创作者分享使用经验
3. **线上工作坊**：举办使用技巧和创作方法的线上工作坊
4. **用户贡献计划**：鼓励用户提交功能建议和 bug 报告，优秀贡献者可获得 Pro 版权益

### 3.4 社区管理

- 设立社区管理员，及时回应用户问题和反馈

- 建立用户反馈收集和处理机制，确保用户声音被听到
