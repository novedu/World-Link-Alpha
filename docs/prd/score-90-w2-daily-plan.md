## 0. 执行前扫描（强制）

每个 Day 开始前必须先扫描当日事项是否已完成（DoD + 证据）。

| 字段 | 填写要求 |
| --- | --- |
| 扫描时间 | YYYY-MM-DD HH:mm |
| 扫描事项 | SCORE-xx |
| 当前状态 | todo / in_progress / blocked / done |
| DoD 判定 | pass / partial / fail |
| 证据链接 | 仪表盘 / 报告 / 截图 |
| 执行决策 | 推进 / 补缺口 / 跳过转下一项 |

## 2. 每日验收证据模板

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| Day | 当天编号 | D4 |
| 日期 | YYYY-MM-DD | 2026-04-30 |
| 执行事项 | 当天涉及的 SCORE 项 | SCORE-02 |
| 完成状态 | pass / partial / fail | pass |
| 核心证据 | 原型链接、截图、日志、录屏 | 链接地址 |
| 风险与阻塞 | 当天未闭环项 | 来源字段缺失历史兼容映射 |
| 补救动作 | 明确到人和截止时间 | 后端负责人 2026-05-01 10:00 修复 |
| 当日结论 | 是否进入下一天计划 | 可进入 D5 |

## 3. 每日站会口径（15 分钟）

1. 激活链路是否仍可在 15 分钟内完成。
2. 追溯视图是否满足“来源可回跳 + 使用可见”。
3. 若出现 P0 回退，暂停新开发，优先修复。

## 4. W2 周结论模板（D7 输出）

| 字段 | 填写要求 |
| --- | --- |
| 周目标达成率 | 完成项 / 计划项 |
| 激活链路数据 | 任务流完成率、步骤耗时、流失节点 |
| 追溯能力数据 | 来源可回跳率、作品使用可见率 |
| 阻断项清单 | 未解决项 + Owner + 截止时间 |
| W3 准入结论 | 允许 / 有条件允许 / 不允许 |

## 5. 失败处理

1. 若 D3 埋点未接入，D4 自动转为埋点补齐日。
2. 若 D5 追溯视图不可用，D6 只允许修复，不接受新增需求。
3. 若 D7 未完成准入结论，需在 2026-05-04 前完成补评审。
