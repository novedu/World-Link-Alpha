- Owner: 产品负责人
- Last Updated: 2026-04-19
- Status: active

## 0. 执行前扫描（强制）

每个 Day 开始前必须先扫描当日事项是否已完成（DoD + 证据）。

| 字段 | 填写要求 |
| --- | --- |
| 扫描时间 | YYYY-MM-DD HH:mm |
| 扫描事项 | SCORE-xx |
| 当前状态 | todo / in_progress / blocked / done |
| DoD 判定 | pass / partial / fail |
| 证据链接 | 仪表盘 / 报告 / 截图 |
| 执行决策 | 推进 / 补缺口 / 跳过转下一项 |

## 2. 每日验收证据模板

## 3. 每日站会口径（15 分钟）

1. 回答是否“带引用且可追溯”，不得仅给结论。
2. 语义检索是否为增强能力，不得破坏结构化筛选主路径。
3. 升级实验不得影响 Free 用户核心链路可用性。

## 4. W3 周结论模板（D7 输出）

| 字段 | 填写要求 |
| --- | --- |
| 周目标达成率 | 完成项 / 计划项 |
| 资产问答质量 | 引用覆盖率、可追溯率、失败率 |
| 语义检索质量 | 召回命中率、无结果率、响应时长 |
| 升级实验数据 | 触发人数、点击率、14 天转化预测 |
| 5/20 门槛预估 | 达标项 / 缺口项 + 负责人 |

## 5. 失败处理

1. 若 D2 无法返回稳定引用，D3 自动降级为“引用修复日”。
2. 若 D4 破坏现有筛选体验，必须回退到“结构化筛选优先”。
3. 若 D7 缺口超过 2 项，触发冲刺路线重排并更新总 PRD 评分解释。
