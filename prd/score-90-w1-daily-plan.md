- Owner: 产品负责人
- Last Updated: 2026-04-19
- Status: active

## 0. 执行前扫描（强制）

每个 Day 开始前必须先扫描当日事项是否已完成（DoD + 证据）。

| 字段 | 填写要求 |
| --- | --- |
| 扫描时间 | YYYY-MM-DD HH:mm |
| 扫描事项 | SCORE-xx / TST-xx |
| 当前状态 | todo / in_progress / blocked / done |
| DoD 判定 | pass / partial / fail |
| 证据链接 | 仪表盘 / 报告 / 截图 |
| 执行决策 | 推进 / 补缺口 / 跳过转下一项 |

## 2. 每日验收证据模板

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| Day | 当天编号 | D3 |
| 日期 | YYYY-MM-DD | 2026-04-22 |
| 执行事项 | 当天涉及的 SCORE/TST 项 | SCORE-06 |
| 完成状态 | pass / partial / fail | pass |
| 核心证据 | 仪表盘、截图、报告、录屏 | 链接地址 |
| 风险与阻塞 | 当天未闭环项 | smoke 报告缺 entitlements 用例 |
| 补救动作 | 明确到人和截止时间 | 后端负责人 2026-04-23 12:00 补齐 |
| 当日结论 | 是否进入下一天计划 | 可进入 D4 |

## 3. 每日站会口径（15 分钟）

1. 昨日承诺事项是否完成（按证据判定，不按口头判定）。
2. 当日阻塞是否会影响 `2026-04-26` 的周目标。
3. 若阻塞影响 P0，立即触发“同日降级决策”（冻结新增功能）。

## 4. W1 周结论模板（D7 输出）

| 字段 | 填写要求 |
| --- | --- |
| 周目标达成率 | 完成项 / 计划项 |
| 指标达成快照 | D1、D7、复用、转化当前值 |
| 阻断项清单 | 未解决项 + Owner + 截止时间 |
| W2 准入结论 | 允许 / 有条件允许 / 不允许 |
| 冻结项清单 | 本周不允许新增的功能范围 |

## 5. 失败处理

1. 若 D5（P0 E2E）未完成，D6/D7 自动转为“补测周”，暂停 W2 启动。
2. 若 D6 仍存在 P0 阻断缺陷，W2 只允许修复，不允许新功能开发。
3. 若 D7 无法形成准入结论，必须在 2026-04-27 前召开额外评审会。
